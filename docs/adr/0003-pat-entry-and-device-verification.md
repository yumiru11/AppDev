# ADR-0003: PAT 开发者模式入口与真机验证流程

- **状态**: Accepted (2026-08-12)
- **相关**: T4（#5 认证）、plan.md PAT 降级
- **决策者**: 用户 + 实施者（grill-with-docs 会话拍板）

## 背景

fine-grained PAT 不支持 GraphQL → 需 REST-only 降级模式；开发者模式需要 PAT 输入入口。T24 设置页未建。

## 决策

1. **PAT 入口**: 登录页底部「开发者模式」**可折叠展开项**（输入 PAT + 保存，附「仅 REST 模式」说明）
   - 理由：登录页是认证域自然入口；折叠不干扰主流程；T24 设置页建成后可迁移
2. **真机验证**: 用户**有真机可验**——T4 验收含真机验证环节：
   - 用户本机跑 `assembleDebug` → 安装真机 → 验证 PKCE 完整回调链路
   - 交付标准 = 逻辑单测全绿 + 真机回调链路验证通过（用户执行，记录验证结果）

## 影响

- T4 验收标准升级：不只是「逻辑测试 + 待真机清单」，而是用户可实操验证
- 需要给用户一份真机验证操作清单（装 APK → 登录 → 刷新 → 重启保持登录 → PAT 降级）
