## 1. A1-3 分区切换时，顶栏跟不跟内容一起动？

**问题**：底部 Tab 左右切换分区时，顶栏（搜索框/铃铛/头像那条）是**跟着内容一起横移**，还是**固定不动、只有内容区移**？

**提示（三种模式的画面感）**：

```
模式 A「整页横移」（iOS 风格）
┌─────────────┐   ┌─────────────┐
│ 顶栏 ███     │ ← │ 顶栏 ███     │   ← 顶栏跟着滑走
├─────────────┤   ├─────────────┤
│ 首页内容      │ → │ 仓库内容      │
└─────────────┘   └─────────────┘

模式 B「外壳固定」（Android 风格）
┌─────────────┐   ┌─────────────┐
│ 顶栏 ███     │   │ 顶栏 ███     │   ← 顶栏不动
├─────────────┤   ├─────────────┤
│ 首页内容 →→  │   │ ←→ 仓库内容   │   ← 只有内容移
└─────────────┘   └─────────────┘

B
```

- **参照**：iOS 的 App（微信/设置）切 Tab = 顶栏内容跟着变（模式 A 的变体）；Android 的 B 站/知乎 = 顶栏独立、内容区移动
- **感受**：A = 「一整页在换」的完整感；B = 「应用外壳包着内容」的稳定感
- **注意**：你现在已有「分区栏」（顶栏下的横条 Tab）。分区栏和顶栏的关系也顺带定一下：分区栏**跟随内容横移**（像 GitHub 网页的 tab 滑动），顶栏固定——这是常见组合
